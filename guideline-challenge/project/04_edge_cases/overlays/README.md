# Owner reference overlays

These annotated images were rendered from the owner’s final calibration export,
`project/06_calibration_exports/dai_v3final.zip`, over the matching BDD100K
source images. Green denotes `direct`; blue denotes `alternative`.

They are visual training examples requested in Group 99’s feedback. They do not
change the frozen decision table or `gold-freeze` tag, and should not be treated
as pixel-perfect frozen masks. The frozen gold remains
`project/04_edge_cases/gold_decisions.csv`; review the source export when exact
geometry is needed.
